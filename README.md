# 「此刻」(CiKe) — 个人成长操作系统

> *看见自己，修炼自己，成为自己。*
>
> 一款帮助迷茫中的人看清自己、修炼底层能力、专注当下的个人成长操作系统。

## 📚 核心设计与技术文档

项目已沉淀两份完整的设计与架构规范，均保存在当前工作目录根目录下：

1. **[产品设计文档 v2 (PRODUCT_DESIGN.md)](PRODUCT_DESIGN.md)**
   - **产品愿景与三层定位**：看见自己（🪞镜+🧭路）、管理自己（📐图+🔥炬）、修炼自己（🏛️修·五艺）
   - **五大核心技能内置修炼体系**：
     1. 🧠 **元学习**（核心：效率 = 输入质量 × 处理深度 × 输出频率，费曼技巧、框架先行、输出倒逼输入、刻意练习）
     2. 💬 **沟通与表达**（核心：效果 = 对方收到的 ÷ 你想传达的，结构化表达、倾听复述、非暴力沟通、刻意输出）
     3. 💰 **财务认知**（核心：自由 = f(收支结构, 复利时间)，记账三个月、三账户思维、基础投资常识、控制负债）
     4. 🧘 **情绪调节**（核心：情绪非问题，自动反应才是，命名情绪、延迟反应、溯源练习、身体调节）
     5. ⏱️ **自律与时间管理**（核心：靠系统设计而非意志力，要事优先、环境设计、最小启动、复盘机制）
   - **「知·观·行·省」四步学习法**与阶梯式解锁机制
   - **交互设计、视觉规范、商业模式与分期规划**

2. **[技术架构方案 (TECHNICAL_ARCHITECTURE.md)](TECHNICAL_ARCHITECTURE.md)**
   - **端云系统架构**：Flutter (iOS/Android/Web) + API Gateway + 模块化服务 + PostgreSQL + Git/Markdown CMS + 端云混合 AI
   - **完整数据模型设计 (ER图)**：用户、记录、目标、签到、专注会话、技能树与单元进度
   - **CMS 体系**：150+ 概念卡片版本化管理规范与增量同步策略
   - **隐私与安全**：端到端加密 (E2EE) 会话密钥流、SQLCipher 本地加密、零广告承诺
   - **分阶段交付里程碑与资源配置建议**
