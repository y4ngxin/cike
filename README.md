# 「此刻」(CiKe) — 个人成长操作系统

> *看见自己，修炼自己，成为自己。*
>
> 一款帮助迷茫中的人看清自己、修炼底层能力、专注当下的个人成长操作系统。

---

## 📚 核心设计与技术文档

项目已沉淀两份完整的设计与架构规范，均保存在当前工作目录根目录下：

1. **[产品设计文档 v2 (PRODUCT_DESIGN.md)](PRODUCT_DESIGN.md)**
   - **产品愿景与三层定位**：看见自己（🪞镜+🧭路）、管理自己（📐图+🔥炬）、修炼自己（🏛️修·五艺）
   - **五大核心技能内置修炼体系**：
     1. 🧠 **元学习**（核心：效率 = 输入质量 × 处理深度 × 输出频率，费曼技巧、框架先行、输出倒逼输入、刻意练习）
     2. 💬 **沟通与表达**（核心：效果 = 对方收到的 ÷ 你想传达的，结构化表达、倾听复述、非暴力沟通、刻意输出）
     3. 💰 **财务认知**（核心：自由 = f(收支结构, 复利时间)，记账三个月、三账户思维、基础投资常识、控制负债）
     4. 🧘 **情绪调节**（核心：情绪非问题，自动反应才是，命名情绪、延迟反应、溯源练习、身体调节）
     5. ⏱️ **自律与时间管理**（核心：靠系统设计而非意志力，要事优先、环境设计、最小启动、复盘机制）
   - **「知·观·行·省」四步学习法**与阶梯式解锁机制
   - **交互设计、视觉规范、商业模式与分期规划**

2. **[技术架构方案 (TECHNICAL_ARCHITECTURE.md)](TECHNICAL_ARCHITECTURE.md)**
   - **端云系统架构**：Flutter (iOS/Android/Web) + API Gateway + 模块化服务 + PostgreSQL + Git/Markdown CMS + 端云混合 AI
   - **完整数据模型设计 (ER图)**：用户、记录、目标、签到、专注会话、技能树与单元进度
   - **CMS 体系**：150+ 概念卡片版本化管理规范与增量同步策略
   - **隐私与安全**：端到端加密 (E2EE) 会话密钥流、SQLCipher 本地加密、零广告承诺
   - **分阶段交付里程碑与资源配置建议**

## 💻 原型目录结构

当前工作目录已包含可交互的运行原型（纯前端 SPA，零依赖、纯本地存储）：

```
d:\project\zhaoxi\cike\
├── PRODUCT_DESIGN.md         # 📄 完整产品设计文档 v2
├── TECHNICAL_ARCHITECTURE.md # 📄 完整技术架构方案
├── README.md                 # 📄 项目索引说明
├── index.html                # 📱 SPA 原型入口
├── manifest.json / sw.js     # 📦 PWA 离线安装与缓存
├── css/
│   └── styles.css            # 🎨 温暖人文设计系统（纸张色、琥珀色、沉静蓝等）+ 暗夜深色模式
└── js/
    ├── skills-data.js        # 🏛️ 五艺内容源（5 技能 × 36 单元，含检验关标记）
    ├── audio.js              # 🎧 Web Audio 白噪音合成引擎
    ├── store.js              # 💾 本地持久化数据中心 + 🔍 自省洞察引擎 + 🏆 结业检验
    ├── router.js             # 🧭 路由系统（支持视图生命周期 & 清理）
    ├── app.js                # 🚀 应用入口与装配层
    └── pages/
        ├── home.js           # 🏠 首页（问候 + 今日一事 + 今日修炼 + 最近记录）
        ├── morning-checkin.js / evening-reflection.js  # ☀️🌙 晨间三问 / 晚间回顾
        ├── mirror.js         # 🪞 记录流（搜索 / 分类 / 编辑 / 自省入口）
        ├── insight-report.js # 🪞 自省报告（周/月模式洞察，只帮"看见"）
        ├── new-record.js     # ✏️ 快速记录（想法 / 行动 / 困惑）
        ├── direction.js / goal-detail.js / new-goal.js  # 🧭 北极星目标与方向日记
        ├── skills.js         # 🏛️ 五艺大厅（进度环 / 等级 / 解锁状态）
        ├── skill-detail.js   # 📚 技能详情（方法论 / 单元路径 / 结业检验入口）
        ├── unit-learning.js  # 🔄 单元修炼（知·观·行·省四步 + 🏆 结业检验提交）
        ├── plan.js           # 📐 四象限计划看板
        ├── focus.js / focus-timer.js  # 🔥 专注面板（含番茄钟卡片）/ 沉浸计时器（正向计时 + 🍅 番茄模式）
        └── settings.js       # ⚙️ 设置与数据主权（导出 JSON / Markdown、导入、重置）
```
